---
title: Keyboard shortcuts
description: Every key Octant answers to, and where it works.
---

Press <kbd>?</kbd> in the app for this list. On macOS <kbd>Cmd</kbd> is the
command key; on Windows and Linux it is <kbd>Ctrl</kbd>.

## Anywhere

These work at all times, also while typing in a text field.

| Keys | What it does |
|---|---|
| <kbd>Cmd</kbd> <kbd>S</kbd> | Save the figure |
| <kbd>Cmd</kbd> <kbd>Shift</kbd> <kbd>S</kbd> | Open the export dialog, with its settings |
| <kbd>Cmd</kbd> <kbd>K</kbd> | Search the variables |
| <kbd>Cmd</kbd> <kbd>Enter</kbd> | Plot the selected variable |
| <kbd>F6</kbd> | Move to the next area: top bar, panels, plot, colorbars |
| <kbd>Shift</kbd> <kbd>F6</kbd> | Move to the previous area |
| <kbd>F10</kbd> | Move to the top bar |

## Outside text fields

Single letters, while no text field has the cursor and no popup or dialog is open.

| Keys | What it does |
|---|---|
| <kbd>?</kbd> | Show the keyboard shortcuts |
| <kbd>D</kbd> | Go to the Dataset panel |
| <kbd>V</kbd> | Go to the Variables panel |
| <kbd>A</kbd> | Go to the Dimensions panel |
| <kbd>S</kbd> | Go to the Settings panel |
| <kbd>B</kbd> | Go to the next colorbar |
| <kbd>P</kbd> | Choose the plot type |
| <kbd>M</kbd> | Type a voice command |
| <kbd>T</kbd> | Show or hide the top bar |
| <kbd>H</kbd> | Show the landing screen, or the plot again |

In a panel, <kbd>Esc</kbd> closes it. On the landing screen, <kbd>Esc</kbd> goes back
to the plot.

## On the plot

While a plot is shown and the plot, or nothing, has focus.

| Keys | What it does |
|---|---|
| Arrows | Pan a 2D plot, turn a 3D one; move the value probe or the crop box |
| <kbd>Shift</kbd> Arrows | Pan further in 2D, pan in 3D; resize the crop box |
| <kbd>+</kbd> or <kbd>=</kbd> | Zoom in |
| <kbd>-</kbd> | Zoom out |
| <kbd>0</kbd> | Reset the view |
| <kbd>Enter</kbd> | Read values with the arrow keys (the probe) |
| <kbd>Esc</kbd> | Stop reading values |
| <kbd>C</kbd> | Show or hide the crop box |

## Playback

On a plot with an animated dimension, such as time.

| Keys | What it does |
|---|---|
| <kbd>Space</kbd> | Play or pause |
| <kbd>,</kbd> | Previous step |
| <kbd>.</kbd> | Next step |
| <kbd>Home</kbd> | First step |
| <kbd>End</kbd> | Last step |
| <kbd>L</kbd> | Turn looping on or off |
