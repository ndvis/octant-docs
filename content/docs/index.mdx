Octant is an interactive viewer for N-dimensional datasets, stored locally or in cloud
object storage. It is built in Rust with GPU rendering, and runs as a desktop app and in
the browser from the same code.

It brings Earth-science and bioimaging data into one app: GRIB forecasts and NetCDF model
output next to OME-Zarr plates, drawn as heatmaps, globes, surfaces or GPU volumes on the
same data.

## Desktop or browser

Octant is built first for the desktop, where it has your GPU, memory and files to itself.
The [web app](https://ndvis.github.io/octant/) runs the same code compiled to WebAssembly,
for a quick look or a shared link. In the browser, a server must allow cross-origin
requests (CORS) for Octant to read it.
